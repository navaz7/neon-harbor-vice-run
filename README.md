**Neon Harbor: Vice Run** — an original open-world crime game that runs entirely in the browser. Explore the fictional port city of Port Azura on foot and by car: steal and drive any car, outrun a 0–5 star police wanted system, fight the rival Bravo cannery crew, and work six story missions for Mama Sol of Sol's Auto Works, plus repeatable side jobs. Live traffic and pedestrians, a day/night cycle, a minimap HUD, synthesized sound, and localStorage saves — all original names, story and code, with zero network requests.

Controls: WASD/arrows to move, E to enter/exit cars, F to fight, mouse to aim and click to shoot, Shift to sprint, M to mute, Esc to pause.

## Run it

```sh
# any static server works; the game is plain files under game/
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a desktop browser
```

Or just open `game/index.html` directly in desktop Chrome — no build step, no network needed.
